# 流程图和时序图

流程图、泳道图、BPMN 流程和时序图生成出来都是普通的 draw.io 图表，所以您可以继续手动编辑。本页介绍请求里应该写些什么，才能得到清晰的初稿。

## 流程图

按顺序描述各个步骤，并写出每个判断和它的结果：

```text
画一张退款申请的流程图：客户提交表单，客服检查订单，如果订单超过 30 天就拒绝申请，否则由财务退款，客户会收到一封邮件。
```

有帮助的做法：

- **说明起点和终点。** “从提交表单到发出邮件。”
- **写出每个判断和它的结果。** “如果订单超过 30 天：拒绝；否则：退款。”
- **说明谁做什么**，就能得到泳道：“客户、客服和财务各一条泳道”。
- **选定方向**：从上到下，或从左到右。

AI 会使用 draw.io 的流程图和 BPMN 图形库：判断用菱形表示；如果要求画 BPMN，事件、网关和任务都会使用 BPMN 图形。

## 时序图

先写出参与者，再按顺序写出它们之间的消息，包括出错的情况：

```text
画一个使用短信验证码的登录时序图，参与者有应用、认证 API、短信服务商和用户。画出验证码连续输错三次时会发生什么。
```

请写明重试、超时和异步回复；否则图里可能只画出一切顺利时的路径。

## 重画已有的流程图

附上白板照片、截图或 PDF，让 AI 重画。结果是一张可以编辑的图表，原来的图片会换成真正的图形和连线。之后照常提出修改，例如“合并两个审批步骤”“在付款之后加一条出错路径”。

借助 MCP 服务器，代理还可以根据您的代码画图，例如“把结账 API 的请求流程画成时序图”。见[在 Claude Code 里使用](./claude-code.md)。

## 让图表更易读

- **“设置”里的图形风格**：“简约”只用朴素的图形，“精致”会加上颜色和图标。见[设置](./settings.md)。
- **动画连接线**可以显示流程的方向；在请求里提出即可。
- **选中图表的一部分**，然后只针对这部分提出修改，例如“让这些步骤间距均匀”。
