# 管理面板

管理面板让您在网页上管理服务端设置，无需手动编辑 `.env`。本页介绍如何开启面板、可以在面板里修改什么，以及设置保存在哪里。

## 开启面板

1. 设置环境变量 `ADMIN_PASSWORD`。没有设置时，面板处于关闭状态。
2. 打开 `/admin`，用这个密码登录。

## 为所有用户提供模型

在“模型”区块里添加服务商，并填入它的 API Key 和模型列表。填写凭据的输入框，和应用[设置](./settings.md)里“模型”标签页的输入框相同。

保存后，这些模型会成为所有用户都能使用的服务端模型。处理请求时，它们会和您环境里的 `AI_MODELS_CONFIG` 或 `ai-models.json` 合并。面板不会修改这些环境文件。

## 修改其他设置

面板的其他区块里有这些设置：

| 区块 | 在这里设置什么 |
|---|---|
| 回复设置 | 生成参数，决定 AI 怎么回复 |
| 访问权限 | 访问码 |
| 可选功能 | 功能开关 |
| 调用记录 | 模型调用的记录（可观测性） |
| 用量限制 | 配额 |

保存的设置会写入 `data/settings.json`，并立即生效，无需重启。少数设置标有“需重启”，例如 Langfuse 和 DynamoDB 的设置：重启服务器后，它们才会生效。

`NEXT_PUBLIC_*` 变量在构建应用时就已固定，所以无法在面板里修改。

## 使用哪个值

同一个设置可能在多个地方都有值。应用按下面的顺序查找，使用最先找到的那个：

1. 面板里保存的值
2. 环境变量
3. 内置默认值

删除面板里保存的值后，应用会重新使用环境变量。

## 设置保存在哪里

- API Key 等密钥以明文形式保存在 `data/settings.json` 里。这个文件的权限是 600，只有文件的所有者可以读写。请不要公开这个文件。
- 使用 Docker 时，`docker-compose.yml` 里的卷会把 `data/` 目录保存在容器之外，所以更换容器后，保存的设置仍然保留。
- Vercel、Cloudflare Workers 等无服务器平台没有能长期保存文件的磁盘，所以面板在这些平台上是只读的。请在这些平台上用环境变量完成所有配置。
