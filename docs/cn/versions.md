# 版本与撤销

AI 的每次修改都会保存为一个版本。您可以先试一个请求，看看结果，不满意再回退。

<!-- demo: ai-edit -->

## 版本卡片

每个修改了图表的回答，末尾都会在聊天里附上一张版本卡片。卡片上有版本号、发生了什么（“画好了图表”“改好了图表”）以及改了哪些内容，例如“新增 1 个图形，新增 1 条连线”。点“查看 XML”可以打开 AI 写的 XML。

画布上被修改的图形会被框出 3 秒钟。在画布当前显示的那个版本的卡片上，点“显示改动”可以再框出一次。

## 撤销上一次修改

画布显示最新版本时，最新的卡片上有“撤销修改”。它会撤回 AI 的上一次修改；之后卡片会显示“这次修改已撤销”，并提供“重做修改”。

在画布上按 Ctrl+Z，同样会撤回 AI 的上一次修改。

如果您在某个版本之后手动编辑了图表，它的卡片上会显示“此版本之后您手动改过画布”。这时“撤销修改”会换成恢复按钮，因为撤销会把您的修改也一起撤掉。

## 恢复更早的版本

较早的卡片上有“恢复到 v1”“恢复到 v2”等按钮。恢复会把那个版本放到画布上，更新的版本仍然保留在列表里，所以之后您还能再恢复其中一个。恢复后会出现一条确认消息，上面有“撤销”按钮，可以回到恢复之前的画布。

## 对比版本

有两个或更多版本后，聊天面板顶部栏下方的“版本”一栏会显示每个版本的缩略图。画布上当前显示的那个版本会被框出来。点击一张缩略图，或者卡片上的缩略图，就会打开“对比版本”：并排显示这个版本和现在的画布，并列出不同的图形。用“上一版”和“下一版”逐个查看，并在那里恢复您想要的版本。

## 在 MCP 服务器中

MCP 服务器的画布旁边也有同样的版本卡片，保留最近 20 个版本。您也可以让 AI 撤销，见[在 Claude Code 里使用](./claude-code.md)。
