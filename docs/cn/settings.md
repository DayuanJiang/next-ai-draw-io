# 设置

从聊天面板打开“设置”。它有四个标签页：“通用”“绘图”“模型”和“关于”。

## 通用

| 设置项 | 作用 |
|---|---|
| 语言 | 界面语言：英文、简体中文、繁体中文或日文 |
| 主题 | 浅色、深色或跟随系统。画布使用同一主题 |
| 发送快捷键 | 回车发送，或 Cmd/Ctrl+回车发送。Shift+回车始终换行，Cmd/Ctrl+回车始终发送 |
| 访问码 | 站点需要访问码时才会显示；访问码由站点所有者提供给您 |
| 代理设置 | 仅桌面应用：为发往 AI 服务商的请求设置 HTTP 或 HTTPS 代理 |

## 绘图

| 设置项 | 作用 |
|---|---|
| 图形风格 | AI 画新图时的风格：“精致”会用颜色和图标，“简约”只用朴素的图形 |
| 用截图检查图表（实验性） | 每次画完后，一个能读图片的模型会查看截图，并要求修正。需要有这样的模型 |
| 自定义指令 | 每次请求时附加到 AI 指令里的文字，例如“始终使用蓝色配色方案” |
| 输出 token 上限 | 单次回答的额度，由模型的思考过程和图表共用。如果 AI 一直在思考却没有画出图表，请把它调大；留空则使用默认值 |

## 模型

演示站自带模型，这些模型不需要 API Key，每天有用量限制。如果想使用其他模型，或者不受这个限制，请用您自己的 API Key 添加服务商：

1. 在“模型”标签页里选择一个服务商，例如 OpenAI、Anthropic、Google、DeepSeek、Amazon Bedrock 或 Ollama。点“获取 API Key”会打开该服务商创建 Key 的页面。
2. 填入 Key。有些服务商还可以填写基础 URL，例如公司的网关或本地服务器。
3. 添加模型：选择推荐的模型，获取服务商的完整模型列表，或者输入模型 ID。
4. “测试”会给每个模型发一条很短的消息，确认 Key 和模型都能用。

然后在聊天框的模型选择器里选择这个模型。API Key 只保存在这台设备的浏览器里，发请求时才带给服务器。

模型需要支持工具调用才能画图。如果 models.dev 显示某个模型不支持工具调用，它会被标为“不支持工具调用”。

自己部署应用时，还可以用环境变量为所有用户配置模型，见 [AI 服务商](./ai-providers.md)。
