# 绘制和编辑

编辑器左边是 draw.io 画布，右边是聊天面板。您在聊天面板里描述想要的图，AI 就在画布上画出来；之后您可以手动修改图表，也可以再次让 AI 修改。

## 开始画图

在聊天框里输入描述，然后按回车。好的请求会说明图里有哪些部分、它们怎样连接，例如“用户登录的时序图，包含短信验证码和失败重试”。

<!-- demo: generate -->

开始页面上的示例展示了编辑器能做什么。选一个示例，再点“发送”：保存好的答案会立即显示，不调用 AI。

如果要从已有的内容开始：

- **图片**：附上截图、白板照片或用其他工具画的图，让 AI 重画。支持 PNG、JPEG、GIF 和 WebP 图片，每张最大 2 MB。
- **文档**：附上 PDF 或文本文件（Markdown、JSON、CSV、YAML、代码等），让 AI 把其中描述的内容画成图。应用会读取文件里的文字，每个文件最多 150,000 个字符。
- **网页**：选择“添加”，再选择“从 URL 提取”，然后粘贴网页地址。
- **draw.io 文件**：附上 `.drawio` 或 `.drawio.svg` 文件，就能在画布上打开它。

一条消息最多可以带 5 个文件。

## 让 AI 修改

在聊天框里提出修改，例如“把数据库改成三个节点的集群”。AI 会修改它看到的图表，包括您手动改过的地方。

如果只想改图表的一部分，请先在画布上选中这些图形。它们旁边会出现“让 AI 改这里”按钮；点击它，或者直接在聊天框里输入。选中的图形会随消息一起发送，所以“把这些改成蓝色”只会修改选中的图形。

回答还在生成时，点“停止生成”就能结束它。在回答下方可以重新生成这条回答；您发送过的消息也可以编辑后重新发送。鼠标移到回答上，还会显示它用了多少输入和输出 token、花了多长时间；再移到这些数字上，可以看到明细，比如其中有多少是从缓存读的。

## 手动编辑

画布就是 draw.io 编辑器，所以 draw.io 的所有功能这里都能用：拖动图形、连接图形、双击编辑标签，以及在右上角的“格式”面板里修改颜色、字体和线条。Ctrl+Z 和 Ctrl+Y 可以撤销和重做您的编辑。

AI 的每次修改都会被框出几秒钟，方便您看清它改了什么。如何回退，见[版本与撤销](./versions.md)。

## 您的图表

图表会在您操作时保存在这个浏览器里。“图纸”列表里保存着每张图表和它的对话：您可以在那里搜索、重命名或删除图表，选择“新建图纸”可以开始画另一张。图表只留在您创建它的浏览器和设备上，所以如果想保留一份副本，或者把它移到别处，请将它导出。

## 导出

“导出”可以把图表保存为以下四种格式之一：

| 格式 | 用途 |
|---|---|
| draw.io 文件 | 所有内容都能继续编辑，在这里或在 draw.io 里都可以 |
| PNG 图片 | 用于幻灯片和文档的图片 |
| SVG 图片 | 放大也不会模糊的图片 |
| 可编辑的 SVG | 一张图片，仍然可以在 draw.io 里打开 |

PNG 可以使用透明背景。

## 常用提示词

把经常用的提示词存起来，比如“画一张……的 AWS 架构图”，之后可以从“常用提示词”列表里再次发送。提示词可以置顶、搜索，也可以导出或导入为 JSON 文件。
