# 繪製和編輯

編輯器左邊是 draw.io 畫布，右邊是聊天面板。您在聊天面板裡描述想要的圖，AI 就在畫布上畫出來；之後您可以手動修改圖表，也可以再次讓 AI 修改。

## 開始畫圖

在聊天框裡輸入描述，然後按 Enter。好的請求會說明圖裡有哪些部分、它們怎樣連接，例如「使用者登入的時序圖，包含簡訊驗證碼和失敗重試」。

<!-- demo: generate -->

開始頁面上的範例展示了編輯器能做什麼。選一個範例，再按「傳送」：儲存好的答案會立即顯示，不呼叫 AI。

如果要從已有的內容開始：

- **圖片**：附上截圖、白板照片或用其他工具畫的圖，讓 AI 重畫。支援 PNG、JPEG、GIF 和 WebP 圖片，每張最大 2 MB。
- **文件**：附上 PDF 或文字檔案（Markdown、JSON、CSV、YAML、程式碼等），讓 AI 把其中描述的內容畫成圖。應用程式會讀取檔案裡的文字，每個檔案最多 150,000 個字元。
- **網頁**：選擇「新增」，再選擇「從 URL 擷取」，然後貼上網址。
- **draw.io 檔案**：附上 `.drawio` 或 `.drawio.svg` 檔案，就能在畫布上開啟它。

一則訊息最多可以帶 5 個檔案。

## 讓 AI 修改

在聊天框裡提出修改，例如「把資料庫改成三個節點的叢集」。AI 會修改它看到的圖表，包括您手動改過的地方。

如果只想改圖表的一部分，請先在畫布上選取這些圖形。它們旁邊會出現「讓 AI 改這裡」按鈕；點選它，或者直接在聊天框裡輸入。選取的圖形會隨訊息一起傳送，所以「把這些改成藍色」只會修改選取的圖形。

回答還在產生時，點「停止產生」就能結束它。在回答下方可以重新產生這則回答；您傳送過的訊息也可以編輯後重新傳送。滑鼠移到回答上，還會顯示它用了多少輸入和輸出 token、花了多長時間；再移到這些數字上，可以看到明細，例如其中有多少是從快取讀取的。

## 手動編輯

畫布就是 draw.io 編輯器，所以 draw.io 的所有功能這裡都能用：拖曳圖形、連接圖形、雙擊編輯標籤，以及在右上角的「格式」面板裡修改顏色、字型和線條。Ctrl+Z 和 Ctrl+Y 可以復原和重做您的編輯。

AI 的每次修改都會被框出幾秒鐘，方便您看清它改了什麼。如何回到之前的版本，見[版本與復原](./versions.md)。

## 您的圖表

圖表會在您操作時儲存在這個瀏覽器裡。「圖紙」列表裡儲存著每張圖表和它的對話：您可以在那裡搜尋、重新命名或刪除圖表，選擇「新增圖紙」可以開始畫另一張。圖表只留在您建立它的瀏覽器和裝置上，所以如果想保留一份副本，或者把它移到別處，請將它匯出。

## 匯出

「匯出」可以把圖表儲存為以下四種格式之一：

| 格式 | 用途 |
|---|---|
| draw.io 檔案 | 所有內容都能繼續編輯，在這裡或在 draw.io 裡都可以 |
| PNG 圖片 | 用於簡報和文件的圖片 |
| SVG 圖片 | 放大也不會模糊的圖片 |
| 可編輯的 SVG | 一張圖片，仍然可以在 draw.io 裡開啟 |

PNG 可以使用透明背景。

## 常用提示詞

把經常用的提示詞存起來，比如「畫一張……的 AWS 架構圖」，之後可以從「常用提示詞」列表裡再次傳送。提示詞可以置頂、搜尋，也可以匯出或匯入為 JSON 檔案。
