# 設定

從聊天面板開啟「設定」。它有四個分頁：「一般」「繪圖」「模型」和「關於」。

## 一般

| 設定項 | 作用 |
|---|---|
| 語言 | 介面語言：英文、簡體中文、繁體中文或日文 |
| 主題 | 淺色、深色或跟隨系統。畫布使用同一主題 |
| 傳送快速鍵 | Enter 傳送，或 Cmd/Ctrl+Enter 傳送。Shift+Enter 一律換行，Cmd/Ctrl+Enter 一律傳送 |
| 存取碼 | 網站需要存取碼時才會顯示；存取碼由網站擁有者提供給您 |
| 代理設定 | 僅桌面應用程式：為傳送到 AI 服務商的請求設定 HTTP 或 HTTPS 代理 |

## 繪圖

| 設定項 | 作用 |
|---|---|
| 圖形風格 | AI 畫新圖時的風格：「精緻」會用顏色和圖示，「簡約」只用樸素的圖形 |
| 用截圖檢查圖表（實驗性） | 每次畫完後，一個能讀圖片的模型會檢視截圖，並要求修正。需要有這樣的模型 |
| 自訂指令 | 每次請求時附加到 AI 指令裡的文字，例如「始終使用藍色配色方案」 |
| 輸出 token 上限 | 單次回答的額度，由模型的思考過程和圖表共用。如果 AI 一直在思考卻沒有畫出圖表，請把它調大；留空則使用預設值 |

## 模型

展示網站內建模型，這些模型不需要 API Key，每天有用量限制。如果想使用其他模型，或者不受這個限制，請用您自己的 API Key 新增服務商：

1. 在「模型」分頁裡選擇一個服務商，例如 OpenAI、Anthropic、Google、DeepSeek、Amazon Bedrock 或 Ollama。點「取得 API Key」會開啟該服務商建立 Key 的頁面。
2. 填入 Key。有些服務商還可以填寫基礎 URL，例如公司的閘道器或本機伺服器。
3. 新增模型：選擇推薦的模型，取得服務商的完整模型列表，或者輸入模型 ID。
4. 「測試」會給每個模型傳送一則很短的訊息，確認 Key 和模型都能用。

然後在聊天框的模型選擇器裡選擇這個模型。API Key 只儲存在這台裝置的瀏覽器裡，傳送請求時才帶給伺服器。

模型需要支援工具呼叫才能畫圖。如果 models.dev 顯示某個模型不支援工具呼叫，它會被標為「不支援工具呼叫」。

自己架設應用程式時，還可以用環境變數為所有使用者設定模型，見 [AI 服務商](./ai-providers.md)。

## 關於

應用程式的版本號，以及專案網站的連結。
