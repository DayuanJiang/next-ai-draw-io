# 版本與復原

AI 的每次修改都會儲存為一個版本。您可以先試一個請求，看看結果，不滿意再回到之前的版本。

<!-- demo: ai-edit -->

## 版本卡片

每個修改了圖表的回答，末尾都會在聊天裡附上一張版本卡片。卡片上有版本號、發生了什麼（「畫好了圖表」「改好了圖表」）以及改了哪些內容，例如「新增 1 個圖形，新增 1 條連線」。點「檢視 XML」可以開啟 AI 寫的 XML。

畫布上被修改的圖形會被框出 3 秒鐘。在畫布目前顯示的那個版本的卡片上，點「顯示改動」可以再框出一次。

## 復原上一次修改

畫布顯示最新版本時，最新的卡片上有「復原修改」。它會撤回 AI 的上一次修改；之後卡片會顯示「這次修改已復原」，並提供「重做修改」。

在畫布上按 Ctrl+Z，同樣會撤回 AI 的上一次修改。

如果您在某個版本之後手動編輯了圖表，它的卡片上會顯示「此版本之後您手動改過畫布」。這時「復原修改」會換成還原按鈕，因為復原會把您的修改也一起撤掉。

## 還原更早的版本

較早的卡片上有「還原到 v1」「還原到 v2」等按鈕。還原會把那個版本放到畫布上，更新的版本仍然保留在列表裡，所以之後您還能再還原其中一個。還原後會出現一則確認訊息，上面有「復原」按鈕，可以回到還原之前的畫布。

## 比較版本

有兩個或更多版本後，聊天面板頂部欄下方的「版本」一欄會顯示每個版本的縮圖。畫布上目前顯示的那個版本會被框出來。點選一張縮圖，或者卡片上的縮圖，就會開啟「比較版本」：並排顯示這個版本和現在的畫布，並列出不同的圖形。用「上一版」和「下一版」逐個檢視，並在那裡還原您想要的版本。

## 在 MCP 伺服器中

MCP 伺服器的畫布旁邊也有同樣的版本卡片，保留最近 20 個版本。您也可以讓 AI 復原，見[在 Claude Code 裡使用](./claude-code.md)。
