# バージョンと取り消し

AI の変更はすべてバージョンとして保存されます。そのため、まず頼んでみて結果を確認し、気に入らなければ元に戻せます。

## バージョンカード

図を変更した回答の最後には、チャットにバージョンカードが表示されます。カードには、バージョン番号、何をしたか（「図を描きました」「図を修正しました」）、何が変わったか（たとえば「図形を 1 個追加、コネクタを 1 本追加」）が表示されます。「XML を表示」を押すと、AI が書いた XML が開きます。

変更された図形は、キャンバス上で 3 秒間枠で示されます。キャンバスに表示中のバージョンのカードでは、「変更箇所を表示」でもう一度枠を表示できます。

## 直前の変更を取り消す

キャンバスに最新のバージョンが表示されている間は、最新のカードに「変更を取り消す」があります。これを押すと AI の直前の変更が取り消され、カードの表示は「この変更は取り消しました」に変わり、「変更をやり直す」が表示されます。

キャンバス上で Ctrl+Z を押しても、AI の直前の変更を同じように取り消せます。

あるバージョンの後に図を手で編集すると、そのカードに「このバージョンの後にキャンバスを手で変更しています」と表示されます。このとき「変更を取り消す」は復元のボタンに替わります。取り消すと、手での編集も消えてしまうためです。

## 古いバージョンを復元する

古いカードには「v1 に戻す」「v2 に戻す」などのボタンがあります。復元するとそのバージョンがキャンバスに表示され、新しいバージョンも一覧に残るので、あとでそちらを復元し直すこともできます。復元するとメッセージが表示され、その「元に戻す」ボタンで復元前のキャンバスに戻れます。

## バージョンを比較する

バージョンが 2 つ以上になると、チャットのヘッダーの下にある「バージョン」の行に、各バージョンの画像が並びます。キャンバスに表示中のバージョンには枠が付きます。画像か、カード上の画像をクリックすると「バージョンを比較」が開き、そのバージョンと現在のキャンバスが横に並んで、違いのある図形の一覧が表示されます。「前のバージョン」と「次のバージョン」で順に切り替え、そこから目的のバージョンを復元できます。

## MCP サーバーでは

MCP サーバーでも、キャンバスの横に同じバージョンカードが並び、直近 20 のバージョンが残ります。AI に取り消しを頼むこともできます。詳しくは [Claude Code から使う](./claude-code.md)を参照してください。
