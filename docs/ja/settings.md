# 設定

設定はチャットパネルから開きます。「一般」「描画」「モデル」「このアプリについて」の 4 つのタブがあります。

## 一般

| 設定 | 内容 |
|---|---|
| 言語 | 画面の言語です。英語、簡体字中国語、繁体字中国語、日本語から選べます |
| テーマ | ライト、ダーク、またはシステムの設定に合わせます。キャンバスも同じテーマになります |
| 送信のショートカット | Enter と Cmd/Ctrl+Enter のどちらで送信するかを選びます。Shift+Enter は常に改行、Cmd/Ctrl+Enter は常に送信です |
| アクセスコード | サイトで必要な場合に表示されます。コードはサイトの運営者から受け取ります |
| プロキシ設定 | デスクトップアプリのみ：AI プロバイダーへのリクエストに使う HTTP または HTTPS プロキシです |

## 描画

| 設定 | 内容 |
|---|---|
| 図のスタイル | AI が新しい図を描くときのスタイルです。「スタイル付き」は色やアイコンを使い、「ミニマル」は素朴な図形だけにします |
| スクリーンショットで図をチェック（実験的） | 描くたびに、画像を読めるモデルがスクリーンショットを確認し、修正を求めます。そのようなモデルが必要です |
| カスタム指示 | リクエストのたびに AI への指示に追加される文章です。たとえば「常に青系の配色を使う」 |
| 出力トークン上限 | 1 回の回答の予算で、モデルの思考と図がこれを分け合います。AI が考え続けて図が出てこない場合は上げてください。空欄にすると既定値を使います |

## モデル

デモサイトには専用のモデルが用意されています。API キーは不要ですが、1 日の上限があります。別のモデルを使う場合や、上限を超えて使う場合は、自分の API キーでプロバイダーを追加します。

1. 「モデル」タブでプロバイダーを選びます。OpenAI、Anthropic、Google、DeepSeek、Amazon Bedrock、Ollama などがあります。「API キーを取得」を押すと、そのプロバイダーでキーを作成するページが開きます。
2. キーを入力します。プロバイダーによってはベース URL も入力できます。たとえば社内のゲートウェイやローカルサーバーの URL です。
3. モデルを追加します。おすすめのモデルを選ぶか、プロバイダーの全モデルの一覧を取得するか、モデル ID を入力します。
4. 「テスト」は各モデルにごく短いメッセージを送り、キーとモデルが使えるかを確認します。

そのあと、チャットのモデル選択でそのモデルを選びます。API キーはこの端末のブラウザにだけ保存され、リクエストのときだけサーバーに送られます。

モデルが図を描くには、ツール呼び出しが必要です。models.dev でツール呼び出しに対応していないとされているモデルには、「ツール呼び出し非対応」と表示されます。

アプリを自分でホストする場合は、環境変数で全員向けのモデルを設定することもできます。詳しくは [AI プロバイダー](./ai-providers.md)を参照してください。
