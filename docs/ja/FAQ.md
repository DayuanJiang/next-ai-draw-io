# よくある質問

このページでは、Next AI Draw.io でよく起きる問題をまとめています。問題ごとに、どんな症状が出るか、なぜ起きるか、どうすればよいかを説明します。

## PDF をエクスポートしても何も起こらない

Web 版で PDF をエクスポートすると、`convert.diagrams.net/node/export` に移動し、そのあと何も起こりません。

アプリに埋め込まれた draw.io エディタは、PDF を直接エクスポートできません。外部の変換サービスを使いますが、このサービスは iframe（ほかのページに埋め込まれたページ）の中では正しく動きません。

まず図を PNG 画像としてエクスポートし、その画像を PDF に印刷してください。

関連する GitHub Issue：#539、#125

## オフラインやイントラネットの環境で、ブラウザが embed.diagrams.net にアクセスできない

イントラネットの環境で、ブラウザに「embed.diagrams.net のサーバー IP アドレスが見つかりません」と表示されます。

アプリには draw.io のコピーが同梱されていて、`/drawio` から配信されます。そのため、ブラウザが `embed.diagrams.net` にアクセスする必要はなくなりました。それでもこのエラーが出る場合は、イメージが `NEXT_PUBLIC_DRAWIO_BASE_URL=https://embed.diagrams.net` でビルドされています。これは以前の Dockerfile の既定値です。このビルド引数を外して、イメージを再ビルドしてください。詳しくは[オフラインや社内ネットワークで使う](./offline-deployment.md)を参照してください。

`NEXT_PUBLIC_*` の環境変数は**ビルド時**の変数で、JS のコードに組み込まれます。**実行時に設定しても効きません。**

別の draw.io サーバーを使い続ける場合は、ビルド時に `args` でそのアドレスを渡します。

```yaml
# docker-compose.yml
services:
  drawio:
    image: jgraph/drawio:latest
    ports: ["8080:8080"]
  next-ai-draw-io:
    build:
      context: .
      args:
        - NEXT_PUBLIC_DRAWIO_BASE_URL=http://あなたのサーバーIP:8080/
    ports: ["3000:3000"]
    env_file: .env
```

イントラネットで使う場合は、外部のネットワークで Dockerfile を修正してイメージをビルドし、そのイメージをイントラネットに転送してください。

関連する GitHub Issue：#295、#317

## 自前のモデルが考えるだけで図を描かない

ローカルにデプロイしたモデル（Qwen、LiteLLM など）が思考過程だけを出力し、図を生成しません。

考えられる原因は 2 つあります。

- **モデルが小さすぎる**：小さいモデルは、ツール呼び出しの指示に正しく従うのが苦手です。パラメータ数が 32B 以上のモデルを使ってください。
- **ツール呼び出しが有効になっていない**：モデルはツール呼び出しで図を描くので、モデルを動かすサービスでツール呼び出しを使えるように設定する必要があります。

モデルを動かすサービスで、ツール呼び出しを有効にしてください。たとえば vLLM では次のようにします。

```bash
python -m vllm.entrypoints.openai.api_server \
    --model Qwen/Qwen3-32B \
    --enable-auto-tool-choice \
    --tool-call-parser hermes
```

関連する GitHub Issue：#269、#75

## 画像をアップロードすると「画像が提供されていません」と表示される

画像をアップロードしたあと、「画像が提供されていません」というエラーが表示されます。

考えられる原因の 1 つは、モデルがビジョン（画像を読み取る機能）に対応していないことです。たとえば Kimi K2、DeepSeek、Qwen のテキストモデルです。

対処法は次のとおりです。

- 画像を読めるモデルを使います。たとえば GPT-5.2、Claude 4.5 Sonnet、Gemini 3 Pro です。
- モデル名に `vision` または `vl` が含まれるモデルは、画像を読めます。
- 最新バージョン（v0.4.9 以降）にアップデートします。

関連する GitHub Issue：#324、#421、#469
